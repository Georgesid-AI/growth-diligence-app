Deleted: the as-of and latest-figure fallback for a claim with no period, in every metric kind of `_observe` and `_growth`; "period not readable" as an Unsupported reason; the first-date borrowing for figures that share one table cell.
Decided: a figure in a cell with other figures of its unit takes the header period of its own position (the cell's header, else the header cells rightwards) and none when the counts differ; the citation is one register field, `observed_citation` "(source key, sheet, rows, period)", written once by Python and read by the screen, the banner, the CSV and the memo, so the four cannot drift; "Contract value" is a metric with no engine source, proposed before any revenue word for a revenue-typed claim, and the deck label of such a figure so it is never a deck inconsistency against revenue; a cumulative or rolling label (ytd, current year, last 12 months, lifetime, to date, rolling) is an exclusion word of the revenue-row rule, not a seventh non-revenue kind, so the model's closed list and S31i stay; a customer-style header over metric labels is recognised with the type unclassed (Customer revenue or Monthly revenue report), Run audit waits for the choice, and the report choice drops the column mapping.
Slow or unclear: the stored audit could not be read from the session (no MongoDB), so the artefact's register rows stood in for `revenue_series.source.rows` and `acv_path`; the exact index of row 39 in the label column is ±1 because the listing does not say which row is the header; George's "(S2, Sheet, rows 5, Jan–Dec 2021)" format names a source key the app has no S-numbered list for, so the evidence source key stands in its place.
